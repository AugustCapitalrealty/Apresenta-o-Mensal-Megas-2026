## Se existir um projeto Apps Script separado

Se houver um projeto de Controle de Acessos rodando no Apps Script cujo
código nunca chegou ao GitHub, é ele que deve ser colado aqui — foi para isso
que a pasta ficou.

Caso contrário, esta pasta pode ser apagada, e o repositório
`Controle-de-Acessos-Megas` arquivado sem perda: ele está vazio.
